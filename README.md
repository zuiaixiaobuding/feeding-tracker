# 小欧欧 · 喂奶记录

一个免费的喂奶记录 App。

宝宝刚出生那阵，除了哭只会"欧欧欧"，就这么叫开了。这个 App 记录的不是哭闹和焦虑，是娃舒服的时候。

## 下载

1. 点击右侧 **「发行版」/「Releases」**
2. 下载最上面那个 `.apk` 文件
3. 手机会提示"未知来源"，去设置里允许即可
4. 装完打开，直接就能用

> 不用注册，不用登录，下载就能用。

## 功能

**喂奶记录**
- 亲喂 / 瓶喂 / 挤奶，一键开始计时
- 支持补记（忘了记也没关系）
- 自动统计今日奶量、喂养次数

**睡眠与尿布**
- 记录睡眠时长、尿布更换
- 首页一眼看到"距上次喂奶多久"

**生长曲线**
- 记录体重、身高
- 对照 WHO 标准百分位，看宝宝发育趋势

**疫苗提醒**
- 内置 22 剂疫苗接种计划
- 自动计算下一针时间，到期提醒

**手表查看**
- 支持 Wear OS / 小米 / 华为等手表
- 喂奶提醒、日程提醒同步到手表，抬手就能看

**数据管理**
- 支持从亲宝宝、宝宝树等 App 导入数据
- 支持导出 CSV 表格（Excel / WPS 可直接打开）
- 支持两台手机之间同步数据

**成长日记**
- 记录宝宝的每个"第一次"
- 支持照片

## 特点

- **永久免费**：没有广告，没有会员
- **不联网**：数据只存在你手机里，不上传任何服务器
- **不用注册**：下载就能用
- **支持多宝宝**：双胞胎、二胎都能分开记录

## 常见问题

**安装时提示"未知来源"怎么办？**

因为不是从应用商店下载的，手机会拦一下。按提示去「设置 → 安全 → 允许安装未知来源应用」，允许一次就行。

**数据会丢吗？**

数据存在手机本地，卸载 App 会一起删掉。建议定期用「设置 → 导出数据表格（CSV）」备份一份。

**换手机怎么迁移？**

用「设置 → 发送同步包到另一台手机」，通过蓝牙或微信发到新手机，接收后会自动合并。

**记错了怎么改？**

在「时间轴」里找到那条记录，点右上角的删除图标删掉，重新记一条就行。
